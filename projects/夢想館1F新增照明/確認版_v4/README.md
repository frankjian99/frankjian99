# 夢想館 1F 新增照明｜確認版

已依確認的第四版 JPG 配置輸出可編輯 DXF。

- 內圈箭頭 14 個；外圈兩道同心弧各 7 個，合計 28 個。
- 太陽符號 24 個，沿用 50% 尺寸。
- BH1A-8 旁新增 1 個綠色空心圓燈具。
- 原右上角圖例表格下方增加三列：LED 17W、LED 25W、LE17W。
- 以上數量不含圖例中的符號。
